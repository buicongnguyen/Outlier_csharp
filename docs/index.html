Study Goal

This site collects revision material for C# software-engineering assessment work. The target skill set: strong command of C# programming including .NET development, object-oriented design, and application architecture, plus experience with the common C# frameworks and tools. Each area pairs a definitions list and core-concept notes with a bank of multiple-choice practice questions and explanations.

Language

C# Language & .NET Runtime

Value vs reference types, generics, delegates and events, LINQ, async/await, garbage collection and IDisposable, records, pattern matching, nullable reference types, and Span<T>.

Design

Object-Oriented Design

Encapsulation and polymorphism, interfaces vs abstract classes, inheritance vs composition, SOLID principles, dependency injection, and the GoF patterns baked into .NET.

Architecture

Architecture, Frameworks & Tools

ASP.NET Core pipeline and DI lifetimes, EF Core, layered and clean architecture, xUnit/Moq testing, configuration and logging, the dotnet CLI, NuGet, and deployment.

Practice format

Question & Coding Drills

102 questions in four formats — single answer, select-all-that-apply, click-the-steps-in-order design chains, and complete-the-code snippets with a gap to fill — including a tagged senior/principal tier (production diagnosis, API evolution, distributed-systems tradeoffs). Plus 14 hands-on coding interview drills (reverse-a-string through deadlocks and async fan-out) with model solutions and interviewer follow-up notes. Per-section and overall scores, show-all toggle, reshuffling retry. Works offline.
